Лабораторная работа №6. 

Цель: Создать веб-приложение на Node.js, которое работает как REST API, раздаёт статику и устанавливается как PWA (Progressive Web App) с поддержкой офлайн-режима.

Задачи:
1) Инициализировать проект ( npm init ), установить Express.
2) Создать сервер, который отдаёт статические файлы (HTML, CSS, JS).
3) Реализовать несколько маршрутов: GET / и GET /about — отдача HTML-страниц.

GET /api/tasks — получение списка задач из массива в памяти (с поддержкой query-параметра ?completed=true для фильтрации).

POST /api/tasks — добавление новой задачи с валидацией данных (возврат ошибки 400, если нет title).4) Научиться работать с параметрами запроса и query-параметрами.
5) Настройка PWA: Создать файл manifest.json, добавить иконки и подключить манифест в HTML, чтобы браузер мог установить сайт как отдельное приложение.
6)Офлайн-режим: Написать и зарегистрировать Service Worker (sw.js), который при первом заходе кэширует статические файлы (HTML, CSS, иконки) и отдаёт их из кэша, когда интернет пропадает



Какие технологии использовались:

1. Node.js — серверная среда выполнения JavaScript.

2\. Express 

3\. npm (Node Package Manager) — менеджер пакетов, использовался для инициализации проекта (npm init) и установки Express (npm install express).

4\. HTML, CSS, JavaScript.

5\. REST API 

6\. PWA-технологии: Web App Manifest (manifest.json) — файл-описание приложения для установки на устройство.

Service Worker (sw.js) — фоновый скрипт браузера, который перехватывает сетевые запросы и управляет кэшем для работы без интернета.
