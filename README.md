Лабораторная работа №6. Введение в Node.js и базовый сервер на Express 
Цель: освоить запуск Node.js-приложений, работу с модулями, создание простого 
HTTP-сервера, а также превращение статического сайта в PWA (устанавливаемое 
приложение с офлайн-режимом).  
Задание: 
 Инициализировать проект ( npm init ), установить Express. 
 Создать сервер, который отдаёт статические файлы (HTML, CSS, JS). 
 Реализовать несколько маршрутов: / (главная), /about (о себе), /api/status (JSON ответ). 
 Научиться работать с параметрами запроса и query-параметрами. 
 Добавить манифест (manifest.json) с иконками и подключить его в HTML. 
 Реализовать service worker: кешировать статику и обеспечить работу приложения 
офлайн, зарегистрировать его на странице. 

Вариант 8. Тема «Список задач» (в памяти) Маршруты: GET /, GET /about, GET 
/api/tasks, POST /api/tasks. Логика: массив задач в памяти. POST с { title: "..." } 
добавляет задачу. GET возвращает список. Query ?completed=true фильтрует 
завершённые. Ответ: [{ id, title, completed: false }] или отфильтрованный массив. 
Ошибки: POST без title → 400.
